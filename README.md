# llm-gateway

Надёжный шлюз поверх нескольких LLM-провайдеров. Главный артефакт проекта —
[RELIABILITY.md](RELIABILITY.md): отчёт с замерами поведения под отказами.

Сборка идёт итерациями: сначала стенд для поломок, затем намеренно наивный
шлюз, затем по одному механизму надёжности за итерацию, каждая — с прогоном
хаос-тестов.
